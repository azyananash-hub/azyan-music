# Benchmarks

Folder ini disediakan untuk pengujian kualitas skill terhadap tugas nyata (mis. membandingkan jawaban AI dengan dan tanpa skill).

**Status: belum ada benchmark yang dijalankan.** Tidak ada angka performa yang dapat dikutip dari library ini sampai benchmark berjalan.

Rencana minimum saat benchmark dibuat:
1. Tugas uji tertulis dengan jawaban acuan yang dihitung (bukan karangan).
2. Dua kondisi: AI tanpa skill vs dengan skill.
3. Metrik: akurasi terhadap acuan, jumlah error, dan waktu.
4. Hasil disimpan dengan tanggal dan versi skill (`sha256_skill_md` di registry).
